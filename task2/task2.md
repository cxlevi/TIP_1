Задание 2. Фильтрация невыполненных задач

Условие задачи:
Реализовать функцию getPendingTasks(tasks), которая принимает массив задач и возвращает новый массив, содержащий только те задачи, которые еще не выполнены (completed: false). Использовать общий набор данных demoTasks.

Как реализовано:
Для решения используется метод массива .filter() со стрелочной функцией task => task.completed === false. Применение строгого равенства === гарантирует, что мы ищем именно булево значение false, исключая ложные срабатывания на 0 или null. Метод .filter() автоматически создает новый массив, поэтому исходный массив demoTasks остается неизменным (соблюдается принцип иммутабельности).
