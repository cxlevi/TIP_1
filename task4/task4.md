Задание 4. Переключение статуса в браузере

Условие задачи:
Реализовать переключение статуса задачи в браузере по клику пользователя. Необходимо использовать делегирование событий, корректно считывать идентификатор задачи из DOM-дерева и обновлять интерфейс после успешного изменения данных.

Как реализовано:
Вместо того чтобы вешать обработчик на каждую кнопку, используется делегирование событий: один обработчик click вешается на родительский контейнер списка задач. При клике с помощью метода .closest() мы поднимаемся по DOM-дереву от цели клика к кнопке действия и к родительской карточке задачи. Из атрибута data-task-id считывается идентификатор задачи. Вызывается функция setTaskCompleted с инвертированным статусом (!task.completed). При получении успешного ответа (result.ok === true) массив задач в памяти обновляется, и вызывается функция renderApp(), которая полностью перерисовывает список и сводку с учетом активного фильтра.
