Задание 3. Изменение статуса задачи (setTaskCompleted)

Условие задачи:
Написать функцию setTaskCompleted(tasks, id, completed) для изменения статуса задачи. Функция должна строго проверять типы аргументов (включая проверку на безопасное целое число для id) и возвращать объект результата { ok: true, tasks } или { ok: false, error }. Исходный массив данных изменять нельзя.

Как реализовано:
Сначала выполняется валидация: проверяется, что tasks — массив, id — положительное безопасное целое число (через вспомогательную функцию isPositiveSafeInteger), а completed — строго тип boolean. Если задача найдена (проверка через метод .some()), создается новый массив с помощью .map(). Для целевой задачи создается её копия через оператор расширения { ...task, completed }, где перезаписывается только поле статуса. Это гарантирует, что исходные объекты в памяти не мутируют.
